## 1. pension-advisor-agent — 연금 상담 Agent

**제10회 미래에셋증권 AI Festival 연금 Agent 트랙 (1인 참가)**

- **조건** — 대회 규정상 지정 LLM(HyperCLOVA X)만 사용 가능. 진행률 0%에서 8일 안에 구현·배포·제출
- **RAG** — 주최 측 문서 58종을 가공해 BM25 인덱스(청크 10,965건) 구축
- **답변 통제** — 조건이 빠진 질문은 되묻고, 세율·한도 계산은 LLM 대신 코드로 처리. 답변마다 검증 증명서를 발급해 근거가 확인되지 않은 문장·수치는 강등
- **배포** — Docker, NCP 서버
- **평가** — 직접 구축한 held-out 40문항 기준 제어 종합점수 92.5%, 필수 근거 평균 recall 85.1%. 문항 단위 전항목 통과율(52.5%) 같은 약한 지표도 함께 기록 (공식 채점 결과 아님)
- **공개 범위** — 주최 측 자료가 포함된 `data/`와 평가 실행 로그는 제외. 코퍼스 구축 절차는 `scripts/01~09`에 남아 있음

## 2. pasteurizer-temp-forecast — 살균 공정 온도 예측

**제9회 인공지능 및 데이터 분석 연구 경진대회 1학년 부문 금상(1위)**

- **데이터** — KAMP 살균기 공정 데이터
- **모델** — XGBoost, Lag·이동통계·시간 변수 19개
- **결과** — 60분 이동평균 베이스라인 대비 MSE 45.7% 감소 (1,317.06 → 715.71)
- **발견** — "직전 1분 값이 가장 중요할 것"이라는 가설 기각. 변수 중요도는 최근 10분 평균 84.1%, 직전 1분 값 9.9%
- **공개 범위** — 원본 데이터 제외, 코드와 결과 그래프만 포함

## 3. cardnews-engine — 수식 PDF → 카드뉴스 자동 생산 엔진

**실제 클라이언트 계정용으로 운영한 1인 프로젝트 (Python 2,729줄)**

- **문제** — 한글 웹폰트에는 수식 기호가 없어 재타이핑이 불가능하고, 문장 중간의 수식은 그대로 잘라내면 휴대폰에서 읽을 수 없음
- **해결** — KaTeX 폰트명으로 수식 영역을 식별 → 정밀 크롭 → 크기 재조정 → 한국어 문장 안에 인라인 배치
- **결과** — 카드 세트(9장) 제작 시간 30~90분 → 약 10분. 카드 99장 실제 생산
- **공개 범위** — 코드만 공개. 원본 PDF·게시 텍스트·렌더링된 카드·클라이언트 브랜딩은 제외
